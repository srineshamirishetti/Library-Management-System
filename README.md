# Library-Management-System
The Library Management System is a project developed by Team Tech Titans (A. Srinesh, R. Supriya, N. Sharvya) using C programming and Data Structures to efficiently manage library operations.
This system demonstrates the practical application of:
Doubly Linked Lists for book management
Queue for handling waiting lists
Stack for tracking recent returns
File Handling for permanent data storage
Key functionalities include adding, issuing, returning, and displaying books, which simplifies library processes, reduces manual work, and improves efficiency.
The project provides a strong practical understanding of data structures and their real-world applications in software development, showcasing how multiple structures can be integrated to build an effective management system.
